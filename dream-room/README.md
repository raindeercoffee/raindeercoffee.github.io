# 夢的部屋

兩間匿名陪睡房：夜潮與霧藍，各最多10人。不用帳號、不聊天。四款夢球隨機分配，可躺下或漂浮。兩房原桌布滿版，毛玻璃控制置於兩旁；霧藍使用專用淡、深雲，另有緩慢極光與星點呼吸。減少動態偏好會停止動畫。

## 本機執行

使用 Node.js 24，npm ci 後 npm run dev。入口 http://127.0.0.1:8787/ 或 /dream-room/。必須啟動服務，不能直接雙擊HTML。

npm run check 檢查語法與23項規則。node tools/audio-schedule-check.mjs 檢查49項聲音排程斷言。服務啟動、兩房空著時，npm run test:runtime:full 實測多人、接管、斷線保留與30秒過期；此工具只准測本機。

## 操作與限制

手機直向選房會先提醒轉橫，轉橫後明確按進入才連線。房內再旋轉仍可操作。手機尺寸模擬不能代替真機瀏覽器、鎖屏、耗電與背景音訊驗收。

音符選柴火、海浪、雨聲、流水或靜音；目前由瀏覽器合成，尚未換成使用者錄音。時鐘選持續、15、30或60分鐘，最後30秒淡出，只關聲音不離房。離開立即清位；斷線保留30秒。同瀏覽器同房後開分頁接管原席位。

首頁九項字體與顏色已依使用者實際選值固定，不再讀暫存調整器。兩房背景、四球、雲朵在 public/assets/；圖示集中 controls-icons.svg。替換素材先保留原檔，並實際檢查手機與桌面。
